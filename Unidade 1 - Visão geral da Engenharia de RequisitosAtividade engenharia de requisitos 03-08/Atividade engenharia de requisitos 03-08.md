**Em duplas, respondam às seguintes questões:**
Quem utilizará o sistema?
Cite 3 requisitos funcionais (o que o sistema deve fazer).
Cite 2 requisitos não funcionais (como o sistema deve funcionar).
Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.
Respostas: 

---

### Respostas

1.   Secretária da escola, Professores, Direção, Alunos e Responsáveis.

2.  - Cadastrar os Alunos (Criar, editar e excluir dados do aluno).
    - Registrar a frequência.
    - Gerar os boletins.

3. - **Segurança e Acesso:** Garantir que o acesso seja feito via login e senha.
   - **Disponibilidade:** O sistema deve estar disponível online 24 horas por dia, 7 dias por semana (principalmente para os professores).

4. Levantar os requisitos antes de desenvolver um software é importante para entender as necessidades do cliente, definir as funcionalidades do sistema, evitar erros e retrabalho, reduzir custos e garantir que o software atenda aos objetivos esperados.
