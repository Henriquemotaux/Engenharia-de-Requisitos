# **Engenharia de Requisitos** — 2º Semestre

Bem-vindo ao repositório dedicado aos estudos, práticas e entregas da disciplina de **Engenharia de Requisitos**, realizada durante o 2º semestre do curso de **Engenharia de Software**.

---

##  Sobre o Repositório

Este espaço tem como objetivo centralizar toda a documentação, exercícios práticos e artefatos produzidos ao longo do semestre. Aqui são aplicadas técnicas e conceitos fundamentais para a identificação, análise, especificação, validação e gestão das necessidades do cliente e do sistema.

---

## 📚 Conteúdo Programático (Unidades)

- **Unidade 1**: Visão Geral da Engenharia de Requisitos
- **Unidade 2**: Análise de Negócio – IIBA BABOK
- **Unidade 3**: Gerenciamento de Processos de Negócio – BPM CBOK
- **Unidade 4**: Caracterização da Engenharia de Requisitos
- **Unidade 5**: Processo de Produção de Requisitos
- **Unidade 6**: Processo de Gerenciamento de Requisitos
- **Unidade 7**: Engenharia de Requisitos no Contexto Ágil
